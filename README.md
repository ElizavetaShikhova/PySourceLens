# PySourceLens
Плагин VS Code для интерактивной визуализации Python-кода

## Установка

1. **Клонирование репозитория**

```git clone https://github.com/ElizavetaShikhova/PySourceLens```

2. **Установите зависимости**

Убедитесь, что установлен Node.js. 
Перейдите в папку расширения (extension) и выполните:

```npm install```

3. **Запустите расширение в режиме отладки**

Откройте папку extension в Visual Studio Code и нажмите F5 или выберите в меню:
Run → Start Debugging.
Это откроет новый экземпляр VS Code — так называемый Extension Development Host.

4. **Откройте целевой проект**

В открывшемся окне Extension Development Host загрузите папку с Python-проектом, который вы хотите проанализировать.

5. **Активируйте плагин**

Нажмите Ctrl+Shift+P (или Cmd+Shift+P на macOS), введите:
PySourceLens: Analyze Code
 и вам будет доступна вся функциональность нашего плагина.

 ## Возможности плагина

 Плагин анализирует Python-проекты и визуализирует их архитектуру:
 
    - Анализ структуры: автоматически строит иерархию проекта — от модулей до функций.
    - Возможность просмотра частей кода.
    - Зависимости: отображает связи между модулями и классами.
    - Интеграция: работает в VS Code.

Подойдёт для быстрого погружения в чужой код, рефакторинга и обучения.

## Похожие аналоги для других языков
1. Java: [JArchitect](https://www.jarchitect.com/?spm=a2ty_o01.29997173.0.0.1c4551712mCwaj)
Парсит .java → строит dependency graph между пакетами, классами, методами.
Показывает вызовы методов, нарушения архитектурных правил (например, «слой A не должен зависеть от слоя B»).
Визуализация: интерактивные диаграммы зависимостей, матрицы связности.
Интеграция: IntelliJ IDEA, Eclipse, CLI.

2. JavaScript/TypeScript: [Madge](https://github.com/pahen/madge?spm=a2ty_o01.29997173.0.0.1c4551712mCwaj)
Строит граф импортов (import ... from ...) и динамических вызовов (если используется анализ через AST).
Генерирует SVG/PNG-диаграммы или интерактивный HTML.
Проверяет правила: «нельзя импортировать из utils в core».
Интеграция: VS Code (через расширения), Webpack.

3. C#: [NDepend](https://www.ndepend.com/?spm=a2ty_o01.29997173.0.0.1c4551712mCwaj)
Полноценный статический анализатор с визуализацией:
* Кто вызывает метод?
* Какие циклические зависимости?
* Метрики сложности 
Использует CQLinq — язык запросов к кодовой базе.
Интеграция: Visual Studio, Azure DevOps.
